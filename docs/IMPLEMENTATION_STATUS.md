# حالة التنفيذ — الإصدار 0.2.0

تم استكمال الوظائف البرمجية المتبقية مع الحفاظ على صلاحيات جهاز البوابة والجهاز الداخلي. النموذج القديم محفوظ؛ التطبيق الجديد في desktop وrenderer وserver.

| الجزء | المنفذ |
|---|---|
| الأفراد | إضافة وتعديل وأرشفة وبحث وملف كامل وصور ومرفقات مركزية حتى 5MB |
| البوابة | خروج وعودة وتصاريح وQR وتصحيح آخر حركة بواسطة المسؤول مع حفظ الأثر |
| الكانتين | حساب بالقروش، كشف شهري وإلغاء مالي بحركة عكسية تمنع الإلغاء المكرر |
| اللياقة | تسجيل القياسات والتقارير وحفظ النتائج النصية المستوردة |
| التقارير | أفراد وحركات وكانتِين ولياقة؛ فلاتر وتصدير CSV وطباعة وPDF، بحد 10000 صف |
| الطباعة | بطاقات وQR وتصاريح، A4/A5، اختيار طابعة وهوامش وعدد نسخ |
| الإدارة | إعدادات وشعار وأسباب خروج وإدارة الحسابات وتعطيلها وإبطال الجلسات وسجل مراجعة |
| النسخ والاستعادة | نسخ مشفرة تشمل المرفقات؛ جدولة كل 24 ساعة واحتفاظ افتراضي 30 يومًا؛ معاينة واستعادة بكلمة مرور ونسخة أمان ومعاملة قاعدة بيانات |
| نقل البيانات | تصدير النموذج القديم ومعاينة واستيراد ذري؛ كشف التكرار والأخطاء دون نقل كلمات المرور القديمة |
| التفعيل | ترخيص موقع لجهاز بوابة وجهاز داخلي، وربط الخادم بمعرف تثبيت وبصمة Windows MachineGuid |
| التوزيع | مثبت Windows ونسخة محمولة وحزمة خادم مستقلة وسكربت تثبيت خدمة WinSW |

## التحقق

ثمانية اختبارات ناجحة واختبار PostgreSQL خارجي متخطى لعدم ضبط TEST_DATABASE_URL. تشمل الاختبارات API والصلاحيات والتوقيع وQR والواجهة، ووظائف الوحدات والاستيراد والنسخ والاستعادة والتراجع عند الفشل.

اختبارات الوحدات تستخدم محرك PostgreSQL المضمن PGlite ومعاملاته الفعلية عبر اتصال واحد؛ لا تثبت التزامن بين اتصالات خادم PostgreSQL مستقل. اختبارات الواجهة تستخدم jsdom وتستبدل مخرجات Electron الأصلية بمحاكاة؛ لا تثبت عمل الطابعة أو PDF الفعلي.

## المتبقي ميدانيًا

1. تجهيز Windows Server وPostgreSQL وشهادات HTTPS وترخيص الجهازين، وتشغيل اختبار قاعدة البيانات الخارجية والتزامن.
2. تجربة النافذة والطباعة وPDF وقارئ USB على جهازي التشغيل.
3. اختبار انقطاع الشبكة وإعادة تشغيل الخدمة والاستعادة من نسخة محفوظة خارج الخادم.

سياسة Windows Application Control في بيئة العمل حظرت تشغيل Electron. أمكن بناء المثبت، لكن لم يتم التحقق من نافذته أو تثبيته أو الطباعة الفعلية. لم يتم تعديل سياسة Windows أو تجاوزها.

الربط الحالي برمجي وDPAPI، وليس مفاتيح TPM غير قابلة للتصدير؛ لا يضمن منع شخص يملك تحكمًا كاملًا من تعديل البرنامج أو استنساخ نظام Windows بالكامل. ربط Active Directory والكاميرات اختياري ولم ينفذ.
