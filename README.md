# نظام شؤون العسكريين

تطبيق Electron عربي (واجهة React + MUI) مع خادم TypeScript وقاعدة SQLite. الهيكل والحالة الحالية في [docs/MIGRATION_PLAN.md](docs/MIGRATION_PLAN.md) (القسم 10).

| الهدف | الأمر |
|---|---|
| تشغيل التطبيق | `npm run desktop` |
| كل الاختبارات | `npm run test:all` |
| اختبار تخطيط الطباعة (عدد الصفحات) | `npm run test:print` |
| اختبار Electron الشامل | `npm run test:electron` |
| المثبّت | `npm run dist` |

## إعداد الطابعات (الإعدادات ← الطباعة)

لكل نوع مستند طابعته الخاصة، و«الافتراضي» يعني طابعة ويندوز الافتراضية:

| الطابعة | تُستخدم لـ | الإعداد |
|---|---|---|
| **XPrinter XP-246B** (ملصقات حرارية) | ملصقات QR للعسكريين والزوار | «طابعة الملصقات» + مقاس الملصق |
| **XPrinter XP-90** (إيصالات 80 مم) | تصاريح البوابة وإيصالات الكانتين | «طابعة الإيصالات» + عرض الورق (58 أو 80 مم) |
| طابعة المكتب | التقارير والبطاقات وكشوف الحساب (A4/A5) | «طابعة المكتب» + مقاس الورق والهوامش |

**خطوات التركيب:** ثبّت تعريف كل طابعة في ويندوز، ثم اخترها من الإعدادات واضغط «طباعة اختبارية» لكل نوع، ثم **احفظ** الإعدادات (الطباعة الاختبارية تستخدم آخر ما حُفظ).

**مقاسات الملصقات الشائعة:** 3.5×4 بوصة (89×102 مم، الافتراضي) · 100×100 · 80×60 · 60×40 · 50×30 مم، أو مقاس مخصص (العرض 20–120 والارتفاع 15–200 مم). يجب أن يطابق المقاس لفة الملصقات المركّبة فعليًا.

**نصائح لطابعة XP-246B:** في تفضيلات التعريف اضبط حجم الورق على نفس مقاس الملصق (أو «مقاس مخصص»)، وعطّل أي تحجيم/«ملاءمة الصفحة»، وعاير الطابعة على اللفة (زر Feed أو معايرة الفجوات) مرة عند تغيير اللفة. إن ظهر ملصق فارغ بين الملصقات فالسبب غالبًا عدم تطابق مقاس التعريف مع اللفة.

**الطباعة المباشرة:** عند تفعيل «طباعة مباشرة بدون نافذة» وتحديد طابعة تُرسل الطباعة دون نافذة ويندوز. أوقفها لتظهر نافذة الطباعة في كل مرة.

الإيصال يُطبع كقطعة واحدة متصلة بطول المحتوى، دون صفحة فارغة أخيرة.
